# 2048 游戏

一款功能完善、视觉精美的 2048 数字益智游戏，基于经典玩法扩展了丰富的游戏体验功能。支持纯前端本地游玩，也可以连接后端服务器实现全服排行榜和成就同步。

## 🎮 在线体验

👉 [点击这里在线游玩（纯前端版本）](https://daseinz1.github.io/2048-game/)

## ✨ 功能特性

### 核心玩法
- **经典2048玩法**：数字方块移动合并，挑战更高分数
- **三种难度选择**：
  - 简单(3×3)：目标分数 512
  - 普通(4×4)：目标分数 2048  
  - 困难(5×5)：目标分数 8192
- **游戏控制**：开始、暂停（ESC键）、重新开始
- **实时计分**：本地存储各难度最高分

### 视觉与动效
- **三套精美主题皮肤**：
  - 经典：暖色调传统风格
  - 深色：暗色系护眼模式
  - 森林：清新绿色主题
- **加载画面**：游戏启动时显示动态加载动画
- **丰富动画效果**：
  - 方块出现动画
  - 方块合并缩放动画
  - 游戏状态过渡动画
  - 成就解锁提示动画

### 音频系统
- **音效反馈**：
  - 方块移动音效
  - 方块合并音效（音调随数值升高）
  - 游戏胜利音效
  - 游戏失败音效
  - 新纪录音效
  - 成就解锁音效
- **音量控制**：支持音量滑块调节
- **静音开关**：一键静音/取消静音

### 进阶功能（本地）
- **本地排行榜**：
  - 记录玩家昵称、分数、用时、日期
  - 支持按分数或用时排序
  - 清空记录功能
- **成就系统**：
  - 🏆 首次通关：首次达到目标分数
  - 🏆 满分挑战：单局得分超过10000分
  - 🏆 速度之王：60秒内达到目标分数
- **游戏分享**：
  - 生成精美成绩卡片（Canvas绘制）
  - 复制分享文本到剪贴板
  - 下载成绩图片
- **操作引导**：首次进入游戏显示详细操作说明

### 在线功能（需要后端）
- **用户系统**：注册、登录、个人信息管理
- **全服排行榜**：跨设备查看所有玩家的成绩排名
- **成就云同步**：解锁的成就会同步到服务器，跨设备保存
- **游戏统计**：查看详细的对战统计数据

### 响应式设计
- **完美适配**：PC和移动端自适应布局
- **触摸支持**：流畅的触摸滑动操作
- **键盘支持**：方向键和WASD控制

## 🚀 快速开始

### 纯前端版本（推荐新手）

无需任何配置，直接打开 `index.html` 即可游玩：

```bash
# 方法1：直接打开文件
双击 index.html

# 方法2：使用本地服务器
cd 2048-game
python -m http.server 8000
# 然后访问 http://localhost:8000
```

### 完整版（前后端）

需要安装 MongoDB，然后启动后端服务：

```bash
# 1. 启动后端服务
cd server
npm install
npm start

# 2. 启动前端（另一个终端）
cd 2048-game
python -m http.server 8000

# 3. 访问 http://localhost:8000
```

详细说明请参考 [server/README.md](server/README.md)

## 🎯 游戏说明

### 操作方式
- **键盘**：使用方向键 ↑ ↓ ← → 或 WASD 移动方块
- **触屏**：在手机上滑动屏幕移动方块
- **暂停**：按 ESC 键或点击暂停按钮

### 游戏规则
1. 相同数字的方块碰撞时会合并成它们的和
2. 每次移动后会随机在空白位置生成新方块（2或4）
3. 达到目标分数即获胜，可继续挑战更高分数
4. 无法移动时游戏结束

## 🌐 在线功能使用指南

### 连接状态
- 启动后端服务后，界面右上角会显示"🟢 已连接服务器"
- 未连接时显示"⚪ 本地模式"，所有功能正常可用

### 用户注册
1. 点击右上角的"注册"按钮
2. 输入用户名（3-20字符）和密码（至少6字符）
3. 可选填写昵称
4. 注册成功后自动登录

### 用户登录
1. 点击右上角的"登录"按钮
2. 输入用户名和密码
3. 登录后自动同步成就和游戏记录

### 全服排行榜
1. 点击左上角的"🏆"按钮
2. 连接服务器后自动显示全服玩家的排名
3. 可切换难度和排序方式
4. 可刷新排行榜获取最新数据
